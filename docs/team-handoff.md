# Материалы для ближайших задач команды

Подготовлено 12 ноября 2026. Первые две задачи Леонида MSG-027/028 завершены по сообщению пользователя; GitHub frontend #1/#2 также закрыты. Новые материалы относятся к следующим двум задачам, а не к повторному выполнению этих работ.

## Решения заказчика

Источник: переданный пользователем документ «Приватный web-мессенджер: план проекта v1» и ответы заказчика на вопросы 29–34. Дата получения ответов не указана.

| Вопрос | Подтверждённое решение |
|---|---|
| 29 | Стек принят, ограничений нет: C# / ASP.NET Core, PostgreSQL, JS/HTML; детали стека — в исходном плане |
| 30 | Фото и короткие видео в MVP; лимит 25 МБ |
| 31 | Групповые чаты сейчас не нужны |
| 32 | Сначала веб-MVP, затем отдельный Avalonia-десктоп, затем Avalonia-Android |
| 33 | Постквантовая устойчивость оформляется обоснованием; отдельная функция сетевого обмена ключами не требуется |
| 34 | РФ, без открытого распространения; рассмотреть использование внутри одной или нескольких организаций |

Ответ 34 задаёт сценарий для аналитиков, а не готовый вывод о применимых правовых нормах. Несколько организаций не означает автоматически подтверждённые федерацию, SSO, административную панель или многопользовательскую изоляцию организаций. Это отдельные вопросы будущего проектирования.

## Статус и порядок работы Леонида

MSG-029: сценарии и состав экранов подготовлены; для закрытия требуется согласование показа ID, ошибок и выхода с backend. MSG-030: спецификация и контрольный пример подготовлены; новые форматы требуют согласования, включая проверку в .NET. Ни одна из этих двух задач пока не заявляется завершённой.

Далее: генерация и формат ключа (13.11), encrypt/decrypt (14.11), IndexedDB и тесты криптомодуля (15.11), интеграция с чатом (16.11), ретро удаления и контракт медиа (17.11), проверка ошибок/выхода (18.11). Интеграционные задачи требуют реальных API и интерфейса; на момент проверки main frontend/backend содержат только README, docs-репозиторий пуст. Это не говорит об отсутствии локальной работы у участников.

Из исходного документа нужно учитывать две оговорки: фраза «офлайн-собеседнику доставлять ничего не нужно» не отменяет синхронизации удалений при reconnect, явно указанной в Must; неизвлекаемость ключа не означает защиту от использования ключа при XSS. Эти уточнения включены в спецификации.
