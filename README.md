# messenger-frontend

Web-клиент приватного мессенджера: HTML + JavaScript (ES-модули), без сборщика и фреймворков.

## Запуск

Нужен Node.js 20+.

```bash
npm run dev
```

Открыть http://localhost:5173. Порт меняется переменной `PORT`.

Пока бэкенда нет, клиент работает с заглушкой API (`src/api/mock.js`): аккаунты хранятся в `sessionStorage` вкладки и пропадают при её закрытии.

## Структура

```
index.html            точка входа, CSP
styles/
  tokens.css          дизайн-токены: цвета, шрифты, отступы, тёмная тема
  base.css            сброс и базовая типографика
  layout.css          каркас страниц и шапка
  components.css      компоненты: кнопки, поля, уведомления, модальные окна…
  screens.css         стили отдельных экранов
src/
  main.js             старт: проверка сессии, запуск роутера
  router.js           hash-роутер, доступ к экранам, очистка при уходе с экрана
  routes.js           таблица маршрутов
  api/                API-клиент; сейчас заглушка
  actions/            действия, общие для экранов (выход)
  state/              состояние в памяти: сессия, одноразовые данные
  screens/            экраны
  ui/                 построение DOM, компоненты, иконки, общие макеты
scripts/dev-server.mjs  локальный статический сервер
```

## Маршруты

| Путь | Экран | Доступ |
|---|---|---|
| `#/login` | Вход | гость |
| `#/register` | Регистрация | гость |
| `#/register/done` | Аккаунт создан, показ ID | гость |
| `#/dialogs` | Список диалогов | вошедший |
| `#/search` | Новый диалог, поиск по ID | вошедший |
| `#/dialogs/:dialogId` | Переписка | вошедший |
| `#/dialogs/:dialogId/key` | Ключ диалога | вошедший |
| `#/account` | Аккаунт: свой ID, хранение ключей | вошедший |
| `#/ui` | Витрина дизайн-системы | все |

Гость на закрытом экране попадает на вход, вошедший на гостевом — к диалогам.

## Дизайн-система

Цвета и размеры задаются только токенами из `styles/tokens.css`, в компонентах нет «магических» значений. Тёмная тема включается по настройке системы.

Компоненты собираются функциями из `src/ui/components.js`: `button`, `field`, `checkbox`, `alert`, `badge`, `spinner`, `loading`, `emptyState`, `avatar`, `confirmDialog`. Все состояния видны на экране `#/ui`.

## Правила

- Никаких inline-скриптов и inline-стилей: CSP разрешает только файлы с того же origin.
- DOM строится через `h()` из `src/ui/dom.js`, текст попадает в страницу как текст. `innerHTML` не используем.
- Пароли, ключи и сообщения не кладём в URL, `localStorage` и логи.
